# Platform Adapters

These files adapt the same PoreMind skill to different agent platforms. The canonical rules remain in the project `SKILL.md`.

- `codex_AGENTS.md`: copy to project-root `AGENTS.md` for Codex-style agents.
- `claude_CLAUDE.md`: copy to project-root `CLAUDE.md` for Claude Code.
- Cursor: reference `SKILL.md` and `api_registry.md` as project documentation; this repository does not currently include a Cursor `.mdc` adapter file.
- `aider_CONVENTIONS.md`: use as Aider project conventions.
- `continue_prompt.md`: use as a Continue custom prompt.
